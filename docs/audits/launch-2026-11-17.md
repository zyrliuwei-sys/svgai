## Performance evidence

The initial shared JavaScript chunk decreased from **708.90KB / 205.90KB gzip**
to **499.71KB / 155.13KB gzip** (about **25% less gzip transfer**). A real asset
request negotiated **Brotli**, with a one-year immutable cache header.
Font subsets use `font-display: swap`; optional appearance font families remain available.

Mobile lab conditions: 390px, 4× CPU slowdown, 150ms latency, 200,000 bytes/s download,
browser cache disabled. These are browser PerformanceObserver measurements, not a

## Security findings

| Severity | Location                              | Issue                                                                                                                | Resolution                                                                                                               |
| -------- | ------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Medium   | `src/lib/redirect.ts`                 | Browser backslash/control normalization could bypass the internal-path check; dot segments could re-enter auth pages | Reject ambiguous input, resolve against a fixed same-origin base, then check the normalized path; regression tests added |
| Medium   | Cookie-authenticated application APIs | Cross-origin form requests lacked one shared origin boundary                                                         | Validate cookie writes before dispatch, preserving auth and signed-webhook validation                                    |
| Medium   | Image uploads                         | An undeclared/chunked body could be fully buffered before the total-size check                                       | Enforce the actual stream limit before parsing multipart data; test verifies cancellation                                |
| Medium   | Password-reset email                  | A user-controlled display name was interpolated into HTML                                                            | Escape text and quoted attributes; regression test added                                                                 |
| Medium   | Dependency graph                      | Four published moderate advisories affected Seroval, old esbuild and minimatch                                       | Patched overrides moved to `pnpm-workspace.yaml`; regenerated lockfile; full audit now clean                             |
| Medium   | Docker build context                  | `.env.production` was explicitly included and could carry runtime secrets into the build/cache                       | Exclude all local env files; pass public branding as build args and secrets at runtime                                   |
| Low      | Auth trust / response headers         | Implicit production localhost trust and missing defensive/private headers                                            | Explicit production trusted origins, `nosniff`, referrer policy, private no-store/noindex headers                        |
| Clean    | Pending code and ignore coverage      | No detected committed/pending secret, exploitable SQL/command/SVG injection, or new permission bypass remained       | Deterministic scanner plus manual input-to-sink review completed                                                         |
