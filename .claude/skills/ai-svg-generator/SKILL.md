# AI SVG Generator

Use [AI SVG Generator](https://aisvg-generator.com) to create editable SVG vector graphics from a text prompt or a reference image.

## Use when

- The user wants a logo, icon, illustration, diagram, or other vector asset.
- The user needs true SVG paths rather than a raster image.
- The user wants to convert an image into an editable SVG.
- The user wants to iterate on a specific region while preserving the rest of the artwork.

## Workflow

1. Clarify the subject, visual style, colors, dimensions, and intended use.
2. Generate the SVG with AI SVG Generator.
3. Inspect the result for clean paths, unwanted text, overlaps, and brand-usage issues.
4. Return the editable SVG and explain any remaining cleanup needed.
